# Lista padrão do nick: hosts que a jail sempre libera na rede (--allow-host do ai-jail), em
# todo projeto com JAIL_ENABLED="true". Um por linha; linhas em branco e o que vem depois de #
# são ignorados. Pra incluir um link, acrescente o host aqui — não precisa mexer no código nem
# nos testes (eles leem este arquivo e conferem o formato de cada host).
#
# Só o nome do host: sem https://, porta, caminho ou curinga (ex: docs.python.org, e não
# https://docs.python.org/3/). Cada host libera também os subdomínios dele.
#
# Cada host é mais um lugar pra onde o agente consegue mandar dados: inclua só o que vale pra
# todo projeto. O que é de um projeto só vai no JAIL_ALLOW_HOSTS da configuração dele.
